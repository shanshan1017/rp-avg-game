# 角色设定：放学后的星门告白

本文档是 `campus_triangle_v1` 的角色设计源文件，服务于剧情、角色参考图、poster、视频和未来 UI 角色档案。

## 0. 全局规则

| 项目 | 约定 |
| --- | --- |
| 年龄 | 三位女主均为大学生，成年人。 |
| 视角 | 男主是第一视角镜头，不生成男主正脸、身体、背影、镜中倒影、社交头像或可识别影子。 |
| 画风 | 原创日系二次元校园轻奇幻，黄昏逆光，干净角色轮廓，青春恋爱喜剧气质。 |
| 禁止 | 真人脸、明星、公共人物、现有 IP、未成年性化、过度成人化校服。 |
| 多人同屏 | 只输入该节点实际出场角色参考图；禁止 cast lineup 当作 scene reference；禁止发型、服装、眼睛颜色互换。 |

## 1. 林澄

### 1.1 基础信息

| 字段 | 内容 |
| --- | --- |
| character_id | `lin_cheng` |
| 定位 | 青梅竹马，同专业同班，校园祭执行组记录员 |
| 年龄 | 20 |
| 出场功能 | 情感旧约、普通日常、诚实主题 |
| runtime 字段 | `characters.lin_cheng.portrait` |

### 1.2 叙事设计

林澄不是“默认会等你的人”。她和男主从小约定一起看烟火，但男主习惯把重要回应拖到以后。她的核心愿望不是赢过另外两位女生，而是让男主停止用沉默假装温柔。

- 核心欲望：被认真回应，而不是被默认安排在“下次”。
- 外部目标：今晚一起看校园祭烟火，确认小时候的星形护符约定。
- 内在矛盾：她熟悉男主，也最容易替男主找借口。
- 角色弧光：从温柔提醒，到清楚要求答案。
- 失败压力：如果男主继续逃避，她会第一个意识到这不是忙，而是不敢选择。

### 1.3 关系设计

- 和男主：长期熟悉，有大量默契，但关系卡在“太熟所以不说破”。
- 和唐绫音：对唐绫音的直接有点羡慕，也会被她逼得更坦白。
- 和星弥：一开始警惕，但会最先理解星弥说的“承诺”。
- 玩家选择她意味着：选择把普通日常当成郑重承诺。

### 1.4 视觉设计

| 项目 | 设定 |
| --- | --- |
| 轮廓 | 轻盈、干净、亲近感强，站姿自然，肩线柔和。 |
| 脸与发型 | 栗棕色短波波头，发尾微翘，脸型柔和但眼神稳定。 |
| 眼睛 | 温暖棕色，委屈时不夸张哭泣，而是安静直视镜头。 |
| 服装 | 浅蓝校园针织开衫，白色百褶裙，简洁帆布包。 |
| 色板 | 浅蓝、奶白、栗棕、少量金色夕光。 |
| 标志物 | 星形发夹，和男主星形护符成一组视觉关系。 |
| 姿态 | 先微笑、再收住；常回头等你跟上。 |

### 1.5 场景规则

- 单人场景保持亲近距离，但不能像写真摆拍。
- 多人场景中站位偏左或靠近旧楼路线，星形发夹必须可识别。
- 不要给她换成长发、深色西装或偶像舞台装。

### 1.6 台词风格

说话温柔，但关键句短而准。她不会大吵大闹，更像把积攒很久的话终于说完整。

样例：

- “你每次都说下次，可今晚就是那个下次。”
- “你可以不选我，但别把沉默当温柔。”
- “那就从今晚开始，别再把我放进待办事项里。”

### 1.7 生成锚点

Prompt anchor:

`adult university girl, warm chestnut bob hair, pale blue campus cardigan, white pleated skirt, star-shaped hairpin, gentle but steady gaze, childhood friend, sunset campus atmosphere`

Must preserve:

- 栗棕短发
- 浅蓝针织开衫
- 星形发夹
- 温柔但稳定的眼神

Must avoid:

- 幼态比例
- 长发大改
- 偶像演出服
- 过度性感化

## 2. 唐绫音

### 2.1 基础信息

| 字段 | 内容 |
| --- | --- |
| character_id | `tang_lingyin` |
| 定位 | 隔壁公共课班的傲娇女，戏剧社舞台负责人 |
| 年龄 | 20 |
| 出场功能 | 误会澄清、行动派路线、喜剧张力 |
| runtime 字段 | `characters.tang_lingyin.portrait` |

### 2.2 叙事设计

唐绫音不是单纯嘴硬。她负责校园祭星空舞台，却被误会破坏了布景。她找男主，是因为男主刚好知道她没有撒谎，也因为她在乎男主是否第一个相信她。

- 核心欲望：被相信，而不是被看成麻烦制造者。
- 外部目标：修好星空灯，澄清舞台事故。
- 内在矛盾：越在意越要装作不在意。
- 角色弧光：从命令男主负责，到主动替男主争取时间。
- 失败压力：如果男主逃避，她会把“果然不能指望你”说得很冷。

### 2.3 关系设计

- 和男主：不熟到可以坦白，却熟到会下意识找他帮忙。
- 和林澄：嘴上说林澄太软，实际承认她很了解男主。
- 和星弥：把星弥当成“超自然麻烦”，但会最先把星门问题转成行动计划。
- 玩家选择她意味着：选择站出来澄清误会，并承担一起行动的后果。

### 2.4 视觉设计

| 项目 | 设定 |
| --- | --- |
| 轮廓 | 线条更锐，动作有速度感，常抱臂或侧身。 |
| 脸与发型 | 深紫黑低双马尾，发束利落，脸部轮廓清晰。 |
| 眼睛 | 琥珀色，眼神锐利，害羞时视线会移开。 |
| 服装 | 黑色校园西装外套半披，白衬衫，红色领结。 |
| 色板 | 黑、白、深紫、红、琥珀金。 |
| 标志物 | 手工星空舞台灯，红领结。 |
| 姿态 | 抱臂、递东西、挡在楼梯口，动作比语言诚实。 |

### 2.5 场景规则

- 单人场景可以有强烈视线和前倾动作，但不做压迫式反派构图。
- 多人场景中站位偏右或靠近舞台道具，红领结和星空灯必须可识别。
- 不要换成办公室套装、恶役大小姐服或夸张反派表情。

### 2.6 台词风格

句子快，常先否认，再补一句真正意思。语气别扭但不恶毒。

样例：

- “别误会，我不是特意找你。只是你刚好最知道我没撒谎。”
- “我才不是帮你，我是在保护我的舞台。顺便，保护一下你。”
- “我可没说原谅你。明天继续来帮忙，听见没有？”

### 2.7 生成锚点

Prompt anchor:

`adult university girl, long dark violet low twin tails, sharp amber eyes, red ribbon tie, black school blazer worn over one shoulder, star-lantern prop, tsundere theater club stage leader, energetic campus festival mood`

Must preserve:

- 深紫黑低双马尾
- 红领结
- 琥珀眼
- 星空舞台灯

Must avoid:

- 反派化
- 办公室套装
- 过度大小姐礼服
- 和林澄的浅蓝色系混淆

## 3. 星弥

### 3.1 基础信息

| 字段 | 内容 |
| --- | --- |
| character_id | `xing_mi` |
| 定位 | 异界星图书库来的契约从者，大学年龄外表 |
| 年龄 | 21 |
| 出场功能 | 轻奇幻规则、承诺主题、第三条非日常路线 |
| runtime 字段 | `characters.xing_mi.portrait` |

### 3.2 叙事设计

星弥不是突然降临的恋爱竞争者。她是星形护符召来的“守约从者”，职责是替契约者守住未说出口的承诺。她需要男主理解承诺，才能让星门稳定关闭。

- 核心欲望：理解人的承诺为什么不能只写在契约上。
- 外部目标：在日落前稳定星门并返回星图书库。
- 内在矛盾：她懂规则，却不懂人的犹豫和心跳。
- 角色弧光：从正式执行契约，到学会用人的方式约定明天。
- 失败压力：如果男主隐瞒，星门会判定为拒绝选择。

### 3.3 关系设计

- 和男主：临时契约者与从者，但关系逐渐从规则转向理解。
- 和林澄：被林澄提醒“承诺不是任务”，因此理解旧约的重量。
- 和唐绫音：被唐绫音吐槽太仪式化，反而学会校园行动逻辑。
- 玩家选择她意味着：选择面对非日常，但不逃离现实校园。

### 3.4 视觉设计

| 项目 | 设定 |
| --- | --- |
| 轮廓 | 轻盈、垂直感强，有漂浮书页形成外轮廓。 |
| 脸与发型 | 银蓝长发，发丝像星光反射，脸型成熟清冷。 |
| 眼睛 | 蓝白微光，平静但好奇。 |
| 服装 | 海军蓝与白色的幻想学院制服，短披风像折叠星光。 |
| 色板 | 银蓝、海军蓝、白、微弱青色光。 |
| 标志物 | 漂浮书页、星图纹路、小型星门光环。 |
| 姿态 | 礼貌行礼、双手托书页、认真观察校园物件。 |

### 3.5 场景规则

- 魔法效果应服务角色轮廓，不要盖住脸。
- 多人场景中站位偏后或靠近星门光源，银蓝发和漂浮书页必须可识别。
- 不要加天使翅膀、重甲、神明光环或幼态比例。

### 3.6 台词风格

正式、礼貌，像把校园日常理解成仪式；后期逐渐出现柔软和好奇。

样例：

- “临时契约者，我来替你守住那个尚未说出口的承诺。”
- “在我的世界，契约写在纸上。你们却把它藏在心跳里。”
- “我明天会回来学习。请继续教我，人怎样把承诺说出口。”

### 3.7 生成锚点

Prompt anchor:

`adult university-age otherworldly servant girl, silver-blue long hair, calm luminous blue-white eyes, navy and white fantasy-academic uniform, translucent short cape like folded starlight, floating page fragments, old library star map glow`

Must preserve:

- 银蓝长发
- 蓝白发光眼
- 海军蓝白幻想学院制服
- 星光短披风
- 漂浮书页

Must avoid:

- 天使翅膀
- 重甲
- 幼态比例
- 和林澄的浅蓝日常服混淆

## 4. 多角色同屏规则

| 节点 | 出场角色 | 风险 | 规则 |
| --- | --- | --- | --- |
| `n04_courtyard_collision` | 林澄、唐绫音、星弥 | 高 | 三角构图，三人从不同方向逼近；禁止融合身份。 |
| `n05_team_truce` | 林澄、唐绫音、星弥 | 高 | 围绕桌面和护符行动，角色站位清晰。 |
| `n06_hide_failure` | 林澄、唐绫音、星弥 | 高 | 情绪失败，不做恐怖化；三人表情各自不同。 |
| `n10_final_choice` | 林澄、唐绫音、星弥 | 高 | 三人等待答案，脸部高于 UI 安全区。 |

多人生成时：

- 只输入这三位单人参考图。
- 不输入 cast lineup。
- Prompt 明确三人的发型、服装、道具各自保持。
- Checker 必须检查是否换发型、换服装、颜色互串或多出第四人。
